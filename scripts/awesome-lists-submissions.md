## How to Submit

1. Fork each repository
2. Add the entry to the appropriate section
3. Create a Pull Request with:
   - Title: "Add ARIA - Production-grade Agentic AI Framework"
   - Description: Brief explanation of why ARIA fits the list
4. Wait for maintainer review
