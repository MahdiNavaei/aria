## Standard Description

Use this description for all submissions:

```
ARIA (Adaptive Reasoning & Intelligent Automation) is a production-grade Agentic AI Framework designed for autonomous task execution with human-in-the-loop safety. Built with LangGraph for stateful orchestration, ARIA features:

- Vision-first UI understanding using VLM
- Local LLM support (Ollama) optimized for 8GB VRAM
- Event sourcing for full auditability and replay
- Cognitive architecture (Brain/Eye/Hand/Memory)
- HITL safety gates for sensitive actions
- Bilingual support (English/Persian)

Perfect for privacy-sensitive, cost-aware, and resource-constrained environments.
```

## Notes

- Most directories review submissions manually (1-7 days)
- Keep descriptions consistent but tailored to each platform
- Include relevant tags/keywords
- Link to GitHub repository and documentation
